# ERRORS — 오류 패턴 인덱스

> 선택 로드 문서. 같은 증상이 재발하거나 원인이 안 잡힐 때 **여기서 번호를 찾아** 해당 파일만 읽는다.
> 같은 오류가 **2회** 발생하면 즉시 추가하고, **3회** 발생하면 `.claude/rules/`로 내린다.
>
> ⚠️ **자기 관리 규칙**: 이 파일은 **인덱스만** 둔다(본문을 여기 붙이지 말 것 — 그렇게 하다
> 360줄이 됐다, D-105). 본문은 아래 두 파일에 쓰고, 그 파일이 **300줄**을 넘으면
> 다시 쪼갠 뒤 이 표에 반영한다.
>
> | 파일 | 담는 것 |
> |------|---------|
> | `docs/errors-runtime.md` | **E-번호** — 코드·라우팅·브라우저·배포·인프라에서 나는 오류 |
> | `docs/errors-ai.md` | **A-번호** — AI(나)가 반복하는 작업 습관 실수 |

## E — 런타임 · 브라우저 · 배포 (`docs/errors-runtime.md`)

| 증상 | 항목 |
|------|------|
| 화면 문구의 개수가 실제 데이터와 다름 | E-1 `count-hardcode` |
| 새 화면이 뒤로가기·직접 접속에서 깨짐 | E-2 `route-partial` |
| **배포 직후에만** 뒤로가기가 빈 화면 | E-2b `stale-screen-id` |
| 공유 링크를 열면 빈 테스트/홈이 나옴 | E-3 `share-fallback` |
| 이전 화면의 타이머·rAF가 새 화면에서 발동 | E-4 `stale-timer` |
| 배포는 됐는데 사이트가 안 뜸 / 직접 접속 404 | E-5 `pages-serving` |
| **로컬에서만** 하위 경로 404 | E-9 `local-server-no-fallback` |
| 특정 브라우저에서만 레이아웃이 깨짐 | E-6 `modern-css` |
| 목업 잔재가 실기기에서 중복/공백으로 보임 | E-7 `mockup-leftover` |
| 결과 유형이 사용자 답변과 모순됨 | E-8 `scoring-flatten` |
| 광고 슬롯 자리는 있는데 광고가 안 나옴 | E-10 `spa-third-party-script` |
| 배너가 2개인데 하나만 채워짐 | E-11 `duplicate-ad-unit` |
| Supabase 로그엔 로그인 성공인데 앱은 비로그인 | E-12 `oauth-redirect-not-allowlisted` |
| Redirect URLs를 고쳐도 여전히 로그인 안 됨 | E-13 `router-strips-oauth-hash` |
| E-13을 고치고 배포해도 실기기에서 로그인 안 됨 | E-14 `implicit-flow-hash-fragile` |
| PKCE로 바꿔도 여전히 로그인 안 됨 | E-15 `oauth-code-exchange-never-fires` |
| **로그인은 되는데 서버에 아무것도 안 쌓임** | E-16 `rls-without-grant` |

> E-12~E-16은 전부 "로그인/저장이 조용히 실패"하는 계열이라 증상이 비슷하다. 순서대로
> 좁혀가는 게 빠르다: 리다이렉트 허용 목록(E-12) → 라우터가 토큰을 지우는가(E-13·E-14) →
> 코드 교환이 실제로 불리는가(E-15) → **테이블 GRANT가 있는가(E-16)**.
